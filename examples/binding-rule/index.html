Binding rule walkthrough

Interpolating a readable (${this.count}) creates a direct binding that updates one DOM position. Reading .value while render() runs subscribes the render, which re-runs once per flush. Reading .value anywhere else (event handlers, timers, promises) is a plain snapshot that subscribes nothing.

The same scenario runs against elements authored in plain JavaScript (no build step) and in TypeScript. Each row counts render() runs and shadow-DOM mutations for one step.
