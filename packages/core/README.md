# @oddkin/core

Authoring foundation: reactive primitives, Scope, OddkinElement, templates, styles, layout recipes, collections, models, registration.

**Status:** M3 in progress. Implemented: `./reactive` and `./scope` (DOM-free), `./template`, `./styles`, `./element`, `./diagnostics` (the root entry re-exports these), `./layout` and `./layout/inspect` (DOM-free recipes), `./collections`, `./model`, and `./model/schema` (DOM-free data contracts), and the optional `./helpers/class-map`, `./helpers/style-map`, `./helpers/ref`, `./helpers/live` (not in the root entry). Contracts: [core-contracts.md](../../docs/architecture/core-contracts.md).
