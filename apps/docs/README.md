# @oddkin/docs (private)

Oddkin's product documentation application. It consumes `@oddkin/*` packages through their public `exports` only and, from M5, embeds `@oddkin/workbench` panels.

**Status:** workspace skeleton (M1). It type-checks against the public package entry points; the documentation shell, Vite dev server, and static build arrive in M5 ([IMPLEMENTATION_PLAN.md](../../IMPLEMENTATION_PLAN.md)).
