Status counts: 7 match, 2 not compared, 1 deliberate, 1 stale snapshot. No mismatch.

**F10, deliberate.** A stroke that stays 1.5 px at every size needs either a non-scaling stroke in each SVG (`vector-effect: non-scaling-stroke`, which `odd-icon`'s `src` mask path cannot apply) or per-size artwork. It belongs to the icon system, not to the button: the same holds for every 16 px icon since the 2026-10-23 icon alignment (which kept Figma's strokes at 1.5 px) and was already the case in v1's 16 px leading icon; the 24 px case is new with v2's large icon-only buttons. At the 20 px default, which most icons use, both draw 1.5 px. The decision is the icon owner's; this run records it as an accepted difference in [component-catalog.md §7](../../../../../component-catalog.md) and does not change 1,723 icons.

**F11, stale snapshot.** The two samples inherit the icon components' stroke binding, which this run moved to the adapter variable. Their resolved colour is unchanged. Four other samples (159:552, 159:559, 159:566, 159:573) no longer exist in Figma since the badge and alert refinement of 2026-11-17, before this run. `packages/components/test/figma-icons.test.ts` compares each sample with its own recorded label colour and passes. A refresh of icon-layouts.json is a separate snapshot task.
