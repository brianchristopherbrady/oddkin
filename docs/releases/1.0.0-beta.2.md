# Oddkin 1.0.0-beta.2 release notes

Published on npm on 2026-11-08 (tag `v1.0.0-beta.2`). What changed for people who install Oddkin since 1.0.0-beta.1 (published 2026-11-01), drawn from [progress-log.md](../progress-log.md). Betas promise no stability; the contract freeze starts at 1.0.0 ([release-process.md](../release-process.md) §1).

```sh
npm install @oddkin/components@beta
```

## Changed

- **The AI elements are drawn with the design system's own parts** ([the component architecture audit](../research/component-architecture-audit.md), approved by the owner on 2026-11-06). Their buttons are native `<button class="odd-button" data-size="sm">` drawn by `nativeButtonStyles`, in place of a private button style. A message's reasoning and `odd-ai-label` are `odd-disclosure`s. One shared controller guards the decision elements against deciding twice and moves focus back when the control you used goes away. Their properties and events stay; some of their parts hold different elements now.
- **The AI elements match the Figma design file's AI page**, in light and dark (P1.8): spacing, type roles, the cards of `odd-sources`, `odd-citation`'s preview, `odd-tool-call`, and `odd-task-plan`, the artifact's toolbar, and the message role labels. Figma parity tests keep them there.
- **`odd-change-review`:** a run of word changes that only whitespace separates reads as one deletion, then one insertion, and a proposal can say where it applies (`context`).
- **Disabled buttons** keep their appearance's colours (primary its fill, secondary its surface and outline, ghost transparent) at 50% opacity, in the element and in `css/button.css`; forced colours keep full opacity.
- **Error messages name what to do.** The messages of every package but `@oddkin/tokens` (18 left) now end with the change that fixes them, and [docs/diagnostics.md](../diagnostics.md) lists every diagnostic code with its message.
- **Smaller bundles:** a bundle keeps only the glyphs it renders (an AI chat bundle loses 604 B), and comments inside the AI elements' style sheets no longer ship.
- **`odd-conversation`:** the message focus ring is offset by `focus.offset`, like every other focus ring.

## Added

- **`odd-table`** (`@oddkin/components`): a data table whose rows and columns come from data typed by two published models, `oddkin.table-columns` and `oddkin.table-rows`, with their JSON Schemas. It sorts (`sort`, `sort-direction`), selects rows, and has empty, loading, and error states. `@oddkin/core/model` gains `m.record` and `m.scalar` for its cells.
- **`@oddkin/components`:**
  - `nativeButtonStyles` in `@oddkin/components/styles`, so other elements draw `<button class="odd-button">` like `odd-button` in their shadow roots;
  - a `summary` slot on `odd-disclosure`, for a summary with formatting, a badge, or a status (it warns once, `disclosure.summary.interactive`, if the slot holds a link or control);
  - layout in composition documents: native containers (`div`, `section`, `header`, `footer`) with `layout.css`'s classes.
- **`@oddkin/ai`:**
  - eight composition patterns in the package's `patterns/` folder, each with a page and a working example in plain HTML, listed in the agent kit: Suggested prompts, Branch navigation, Reasoning disclosure, Copy action, Empty conversation, Chat layout, Citations with sources, and Approval outside a tool call;
  - one `renderers` property by extension point (`data`, `artifact`, `toolOutput`) on `odd-conversation`, `odd-message`, `odd-tool-call`, and `odd-artifact`;
  - examples that play the host for every element, so their controls show what happens.
- **`@oddkin/tokens`:**
  - theme files that extend a shared base (`extends`), and product colour roles; a product's brand no longer moves another product's values;
  - the foundation inputs `radius.scale`, `motion.scale`, and `typography.scale`;
  - Display P3 values with `"gamut": "p3"`;
  - Sass modules beside the CSS and TypeScript outputs;
  - `resolveTokens(theme, context)` in `@oddkin/tokens/generate`;
  - descriptions for the roles that only name another token, in the inspection and the DTCG output.
- **`@oddkin/workbench`:**
  - Theme Studio as one embeddable panel, `<oddkin-theme-studio-panel>` (`@oddkin/workbench/panels/theme-studio`), with screens of any documented component and composition screens, four starters among them (an app layout with `odd-table`);
  - in `oddkin workbench dev`, saving a theme file after showing its diff, theme files on bases, several themes and their products, and opening your own app with the draft;
  - Shape, motion, and type controls, and the ramp and contrast views;
  - share links made by 1.0.0-beta.1 open in this version;
  - the schemas of your configuration and content files in `@oddkin/workbench/schemas/`.
- **`@oddkin/analyzer`**, for libraries not built with Oddkin:
  - `oddkin-analyze --manifest <custom-elements.json>` (examples from a standard manifest) and `oddkin-analyze --declarations <index.d.ts>` (a manifest from published declarations);
  - agent kits, change impact, and Workbench from a standard Custom Elements Manifest alone;
  - a library's composition catalog and schemas from its manifest (`@oddkin/analyzer/composition`);
  - `oddkin-impact snapshot --source <repo-dir>` records the commit and whether the tree had changes; a product's examples choose its checks;
  - `@oddkin/analyzer/metadata` (`checkMetadata`), and the schemas of products and impact artifacts in `@oddkin/analyzer/schemas/`.

## Deprecated

Each still works in this beta and goes in the next one:

- **`odd-suggestions`:** use the Suggested prompts pattern (`odd-button`s in a labelled group).
- **`odd-message-branch` as a public element:** it stays inside `odd-message`; its registration entry goes.
- **`renderTool`, `artifactRenderers`, and `renderOutput`:** use `renderers` (`toolOutput`, `artifact`). A `renderers` map in the old shape (data renderers by name) still works, with one warning (`ai.renderers.legacy`).
- **`odd-checkpoint`'s `strings.available`:** unused.

## Upgrading

- **npm:** no change is needed. The change-impact report against 1.0.0-beta.1 (the components and AI packages) finds 544 changes, none incompatible.
- **Styles through `::part()`** in the AI elements: some parts now hold `odd-button`s, `odd-disclosure`s, or a toolbar region; check rules that reach inside them.
- **Before the next beta**, replace the deprecated names above.

## Known issues and limitations

From the [support policy](../support.md):

- Safari is tested through Playwright's WebKit, not on Apple hardware, and mobile browsers are not tested.
- Screen readers are not yet verified.
- pnpm, Yarn, webpack, Rspack, and Node.js below 24 are not tested, and server-side rendering is not supported.
- `@oddkin/workbench` and `@oddkin/analyzer` keep their contracts open after 1.0.0 (ADR 0047).
