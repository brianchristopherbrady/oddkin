# Security policy

## Reporting a vulnerability

Report security problems privately through GitHub: open this repository's **Security** tab and choose **Report a vulnerability** ([new report](https://github.com/brianchristopherbrady/oddkin/security/advisories/new)). Please do not open a public issue.

Include the package and version, what an attacker could do, and the steps to reproduce it.

## Supported versions

During the `1.0.0` betas, only the latest beta receives fixes; a fix ships in the next beta. See [docs/support.md](./docs/support.md) for what each release is tested with.
